# 骑马钉小册子拼版检查 Web 应用

一个用于核对骑马钉（saddle-stitched）小册子拼版是否正确的小工具：输入成品页数后自动补齐为 4 的倍数，按纸张装订后的嵌套顺序预览每张纸正 / 反面的左右页码与空白版位；可以交换任意两个版位，系统实时标出**重复页、缺页、空白版位数量异常及同张正反配对异常**，存在错误时禁止导出；校验通过后可下载包含纸张序号、面别和左右页码的 CSV。

技术栈：**Node.js + Express + 原生 HTML/CSS/JavaScript**（拼版逻辑封装为零依赖 UMD 模块，前后端共用同一份代码）。

---

## 快速开始（Docker）

```bash
docker compose up --build
```

启动后在浏览器访问：<http://localhost:3000>

停止：

```bash
docker compose down
```

## 本地运行（无 Docker）

要求 Node.js ≥ 18。

```bash
npm install
npm start
```

然后访问 <http://localhost:3000>。端口可用环境变量 `PORT` 覆盖（容器内固定监听 3000）。

## 使用说明

1. 在「成品页数」输入实际页数（1～120 的整数），点击 **生成拼版**（或按回车）。
   - 系统自动向上补齐为 4 的倍数，空白页统一补在文档末尾，并在版位中标记为「空白」。
2. 界面按装订后的**嵌套顺序**列出纸张：第 1 张为最外层，依次向内，最后一张为中缝最里层。
3. 检查 / 编辑版位：
   - **交换**：点击任意版位选中（蓝色高亮），再点击另一个版位，即交换两者内容；按 Esc 或再次点击同一版位可取消选择。
   - **直接指定**：每个版位内有下拉框，可直接把该版位设为某页或空白（用于构造重复页 / 缺页等异常）。
4. 系统实时校验并标红 / 标黄问题版位，顶部列出中文问题清单：
   - **重复页**：同一真实页码出现在多个版位（红色「重复」标记）。
   - **缺页**：1～成品页范围内有页码未出现；同时校验空白版位数量是否与补齐页数一致。
   - **同张正反配对异常**：某张纸四个版位与标准拼版不符（黄色「配对异常」标记，异常纸张顶部有徽章）。
5. 点击 **制造异常示例** 可随机打乱几个版位，快速观察检查效果；**恢复标准拼版** 一键还原。
6. 只有全部校验通过时 **导出 CSV** 按钮才可用。前端与服务端各做一次校验，服务端对任何异常都返回 `400` 拒绝导出。

CSV 格式（UTF-8 带 BOM，Excel 直接打开不乱码），按纸张嵌套顺序、每张先正面后反面：

```csv
纸张序号,面别,左页码,右页码
1,正面,8,1
1,反面,2,7
2,正面,6,3
2,反面,4,5
```

空白版位导出为 `空白`。

## 拼版规则

一张纸对折后产生 4 个版位。设补齐后的总页数为 N，第 s 张纸（s 从 1 开始）：

| 面别 | 左 | 右 |
| --- | --- | --- |
| 正面 | N − 2(s−1) | 2s − 1 |
| 反面 | 2s | N − 2s + 1 |

同一面左右两码之和恒为 **N + 1**。以成品 8 页（无需补白）为例：

```
纸张1（最外层）  正面  8 | 1     反面  2 | 7
纸张2（里层）    正面  6 | 3     反面  4 | 5
```

成品 6 页时补齐为 8，页码 7、8 为补在末尾的空白页：

```
纸张1  正面  空白 | 1     反面  2 | 空白
纸张2  正面  6 | 3        反面  4 | 5
```

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/healthz` | 容器健康检查 |
| GET | `/api/signature?pages=8` | 生成标准拼版方案（含自动补齐与初始 assignments） |
| POST | `/api/validate` | 入参 `{ pages, assignments }`，返回逐类问题与中文消息 |
| POST | `/api/export` | 入参同上；校验通过返回 `text/csv`，否则 `400` 拒绝 |

`assignments` 为一维数组，每张纸按 `[正面左, 正面右, 反面左, 反面右]` 排列，元素为正整数页码或 `null`（空白）。
